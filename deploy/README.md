# `deploy/`

Everything needed to install the platform.

| Path | Contains |
|---|---|
| [`charts/platform-core/`](charts/platform-core/) | **one chart** that installs an empty platform |
| [`policies/`](policies/) | the Rego policy bundle — we write it, modules never do |

## Note on cluster state

Per team practice, anything actually applied to a real cluster is recorded in
`~/bss/infrastructure/k8s` with its README change history. The chart is developed here; what is
deployed is tracked there.

## One chart, not twelve

A customer runs one command. Dependencies (Keycloak, Istio, Flux, CloudNativePG, Strimzi,
kube-prometheus-stack) are subcharts gated by flags:

```yaml
# charts/platform-core/values.yaml
profile: full          # full | lite — `lite` skips the mesh, Kafka and HA for labs

global:
  domain: platform.acme.example
  # Air-gapped sites point this at a local mirror. No chart edits, no image retagging:
  # every image reference in every subchart derives from this value.
  registry: harbor.bssconnects.io

keycloak:
  enabled: true
  # Customers with their own IdP still get OUR Keycloak, federated outward to theirs.
  # Supporting "bring your own Keycloak" would mean supporting every version they run.
  externalIdP:
    enabled: false

istio:
  enabled: true
  # Ambient removes the per-pod Envoy, cutting ~150-250 MiB per replica. Decide before
  # sizing the first customer cluster, not after.
  mode: sidecar        # sidecar | ambient

kafka:
  # Installed ON DEMAND when the first module requiring it is licensed, so the lite
  # profile stays viable for small customers and labs.
  enabled: false

opal:
  # Phase 2. Phase 1 uses bundle polling: correctness first, propagation latency second.
  enabled: false
```

## Rules

- **No module charts here.** Module charts live with their modules and are published to Harbor
  as OCI artifacts; the operator references them.
- **`helm template` must produce valid manifests with default values.** CI enforces this.
- Every image reference derives from `global.registry`, or air-gapped installs break.
- CRDs live in `crds/` and are generated by `make generate` — never hand-edited.
