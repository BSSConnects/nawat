# `examples/hello-module`

The reference module. One resource (`Widget`), six fields, one action (`retire`).

## Layout

```
main.go                 wires pkg/sdk and starts the server
widget.go               the Widget type and its store
store_memory.go         in-memory store — phase 1 needs no database
__metadata__.json       GENERATED by the SDK; committed so reviewers see contract changes in diffs
chart/                  Helm chart, published to Harbor as an OCI artifact
  values.schema.json    drives the install form the UI generates
```

Committing the generated `__metadata__.json` is deliberate: a PR that changes a field then shows
the contract change in the diff, where a reviewer will see it.

## Example — the whole module

```go
package main

func main() {
    mod := sdk.NewModule(sdk.Config{
        ID: "hello", Version: "0.1.0", BasePath: "/api/hello/v1",
    })

    // Permissions are DECLARED here and discovered by the platform on install. Four for one
    // resource — not sixteen. `list` and `search` are the same capability as `read`;
    // "only my own records" is a binding SCOPE, not a permission. Getting this wrong
    // produces a role builder no customer can use.
    mod.DeclarePermissions(
        sdk.Perm("hello:widget:read",   "View widgets",   "Read and list widgets."),
        sdk.Perm("hello:widget:write",  "Edit widgets",   "Create and update widgets.",
            sdk.Implies("hello:widget:read")),
        sdk.Perm("hello:widget:retire", "Retire widgets", "Take a widget out of service.",
            sdk.Implies("hello:widget:read")),
        sdk.Perm("hello:widget:pii",    "View serials",   "See manufacturer serial numbers.",
            sdk.Implies("hello:widget:read")),
    )

    sdk.Register(mod, sdk.Resource[Widget]{
        Type:  "hello/Widget",
        Names: sdk.Names{Singular: "Widget", Plural: "Widgets",
                         Collection: "widgets", CLIAliases: []string{"w"}},
        Docs: sdk.Docs{
            Summary: "A device managed by the hello module.",
            // These examples become `bssconnectsctl hello widgets --help`, so the CLI
            // documents modules that did not exist when the CLI was built.
            Examples: []sdk.Example{{
                Title: "List active widgets",
                CLI:   "bssconnectsctl hello widgets list --filter status=active",
            }},
        },
        Identity:    sdk.Identity{IDField: "id", DisplayField: "name"},
        Permissions: sdk.Permissions{Read: "hello:widget:read", Write: "hello:widget:write"},
        Authorization: sdk.Authorization{
            TenantField:   "tenantId",
            ListFiltering: sdk.PartialEval,
        },
        List: sdk.ListConfig{
            Columns:     []string{"name", "status", "createdAt"},
            DefaultSort: "-createdAt",
            Search:      []string{"name", "serial"},
            Filters:     []sdk.Filter{{Field: "status", Type: sdk.FilterEnum}},
            RowActions:  []string{"retire"},
        },
        Actions: []sdk.Action{{
            ID: "retire", Label: "Retire", Permission: "hello:widget:retire",
            // availableWhen drives whether the UI shows the button AND whether the API
            // accepts the call — declared once, enforced in both places.
            AvailableWhen: sdk.FieldIn("status", "active"),
            Confirm:       sdk.Confirm{Required: true, Danger: true},
            Handler:       retireWidget,
        }},
        Store: NewMemoryStore(),
    })

    log.Fatal(mod.ListenAndServe(":8080"))
}
```

## Exit test for phase 1

```bash
bssconnectsctl license apply testdata/hello.lic   # module appears as Available
bssconnectsctl module install hello --set greeting=hi
bssconnectsctl hello widgets list                  # works, with no hello-specific CLI code
# and the same rows appear in the UI, with no hello-specific React code
```
